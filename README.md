# RoCo Spray Foam Insulation

Marketing site for RoCo Spray Foam Insulation, concrete, and masonry in Central Minnesota. Built with Next.js and deployed on Vercel.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Vercel detects Next.js automatically. Build command is `next build`. Requires Node.js 20.9 or later. No environment variables are needed.
